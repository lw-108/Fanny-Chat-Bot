# 🤖 Lingeshwarma Meme Chatbot  
### Desktop Chatbot with Meme Reactions, GIF Popups & Sound Effects (Windows)

A fun and interactive **desktop chatbot application** built using **Python + Tkinter**, featuring **rule-based conversation**, **automatic meme reactions**, **animated GIF popups**, and **WAV sound effects** for unknown or funny inputs.

Designed as a **college-ready desktop project** with EXE and installer support.

---

## 🚀 Features

- 🤖 Rule-Based Chatbot (NLTK)
- 🪟 Clean Desktop UI (Tkinter)
- 😂 Animated GIF Meme Popups
- 🔊 WAV Sound Effects (No external libs)
- 🎯 Automatic Unknown-Word Detection
- 🧠 Smart Fallback Responses
- 🖼 Random Meme Selection
- 📦 EXE & Installer Ready
- ❌ No Terminal Window (GUI-only app)

---

## 🧩 How It Works

- User types a message in the chatbot window
- If the input matches known patterns → normal reply
- If input is **random / unknown** →  
  👉 Meme GIF pops up  
  👉 WAV sound plays  
  👉 Fun reaction appears 😆
